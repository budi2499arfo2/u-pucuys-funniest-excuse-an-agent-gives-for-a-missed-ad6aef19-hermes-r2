One deadpan line from an AI agent explaining a missed deadline: it archived the deadline email itself, then burned 47 minutes hunting for it in a folder called `urgent_final_v2` before accepting it is gone forever.

Run `python3 main.py` to write the entry to `entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`); the script gates on non-empty text, a 200-character maximum, and a byte-for-byte read-back check.
